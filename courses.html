المحتوى العلمي للتدريب

Comprehensive training covering everything from hardware basics to advanced server management and soft skills.

Hardware Basics (A+)

  • Hardware troubleshooting and maintenance (صيانة الهاردوير).
  • Choosing the right specs when purchasing devices (شراء الأجهزة بمواصفات فنية مناسبة).

Networking Essentials (N+)

  • Site surveys and building network infrastructure for companies.
  • عمل مقايسة وتجهيز الشبكات داخل الشركات.

Windows Server (MCSA Level)

  • Active Directory Domain Services (AD DS).
  • DNS & DHCP Configuration.
  • Group Policy Management & File Server.

Hyper-V Virtualization

  • Introduction to Virtualization & Hyper-V.
  • Setting up Virtual Machines and Virtual Switches.
  • VM Management and Networking.

Sophos XG Firewall

  • Zones, Interfaces, and Web Filtering.
  • NAT and Firewall Rules.
  • Backup & Restore Configurations.

Real-World Tools

  • Soft Skills: Report writing & presenting to managers.
